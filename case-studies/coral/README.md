# Coral case study

This example compares a barrier SPDE model and a standard SPDE model using global Scleractinia records from GBIF.

## Scripts

- `gbif_download_cleaning.R`
- `coral_example.R`

## Required input files

These files are not included in the GitHub repository because they can be large:

- `dat_clean_marine.RData`
- `barrier_polygon_YYYY-MM-DD.geojson`
- `MOBIE_mesh_YYYY-MM-DD.RData`

The GBIF cleaning script can be used to generate the cleaned Scleractinia dataset.
