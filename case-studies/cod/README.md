# Cod case study

This example fits a hurdle spatial model for *Gadus morhua* using a barrier and spherical mesh exported from MOBIE.

## Scripts

- `cod_example.R`

## Required input files

These files are not included in the GitHub repository because they can be large:

- `FishGlob_public_clean.csv`
- `barrier_polygon_YYYY-MM-DD.geojson`
- `MOBIE_mesh_YYYY-MM-DD.RData`

Place the files in the working directory used by the script, or edit the file paths inside the script.
